An explicit no. gh's mandatory field list is a real compatibility mechanism and it does not transfer: gitchange's snapshot is computed before printing (selection saves nothing), the document is a nested tagged union a flat name list cannot address, and every selectable name widens the public API it is meant to protect. The version field plus the additive contract do the compatibility job; payload size is handled by scoping and `--no-content`, never projection. What is borrowed from gh instead is its error shape: an unrecognised changelist name or hunk ID lists the valid candidates.
