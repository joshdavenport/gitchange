A flag carries a short form iff its command borrows a git grammar and git's own spelling of that flag has the short — shorts arrive wholesale with the borrow (`changelist`: `-d`, `-D`, `-f`, `-m`; `commit`: `-m`, `-F`, `-n`) and never otherwise. Gitchange-native flags (`--to`, `--containing`, `--take-owned`, `--allow-*`, `--unassign`, `--json`) stay long-only: the typed caller is usually an agent, which pays no typing cost; refusal text teaches the long, condition-naming form (ADR 0015); and an invented letter can imply a git meaning it does not have (`-u` beside `git add -u`, `-c` beside git's create/copy). `--to` — required on every `assign` — was the weighed borderline and stays long-only.
