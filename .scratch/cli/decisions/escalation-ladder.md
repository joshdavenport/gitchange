`assign <path> --to <changelist>` → refusal names the owner → add `--containing <line>` → refusal lists candidate hunk IDs or names the owner → scoped `diff --json <path>`, or escalate to the human. Each refusal's text is the instruction for the next rung (agents navigate by error text). The happy path is one command and zero reads. The skill teaches assign-as-you-go, never batched: immediate assignment keeps a file's unassigned pool near-empty, which is what makes the path-level sweep safe.
