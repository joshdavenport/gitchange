The CLI has no editor, so every commit names its message source explicitly: `-m` (git's full grammar — multiline values, repeated `-m` as paragraphs), `-F <file>` with `-` for stdin, or, with `--amend`, `--no-edit` to keep HEAD's message. No source, or two together, is a usage error — git itself refuses `-m` with `-F`. The set covers the message shapes real agent sessions use (heredoc into `-m`, `git commit -F - <<'EOF'`); `--trailer` is message editing, not provision, and stays unborrowed.
