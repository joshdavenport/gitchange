The value is a fixed string matched as a substring of changed-line content (`+` and `-` sides), verbatim bytes — pickaxe's shape, not `add -p`'s regex. Refusal-on-ambiguity makes substring's forgiveness cost no safety: over-match is loud, and substring turns whitespace-quoting fumbles into hits where a regex's unescaped metacharacter would change the match silently. Context lines are excluded because they belong to code the agent did not write — matching them selects other actors' changes, the misassign the flag exists to prevent. A within-file move puts the same line on both sides in two hunks and trips the multi-match refusal; the refusal's ID list is the resolution (`assign <path>:<idA> <path>:<idB>` takes both in one exact retry), so there is no allow-multiple or side-filter flag — allow-multiple would turn an address into a sweep that quietly broadens.
